## Before publishing
1. Choose and connect the final domain.
2. Add a public professional email address and LinkedIn URL only after those are created.
3. After the domain is known, add absolute canonical URLs and `hreflang` URLs to both pages.
4. Rename `sitemap.template.xml` to `sitemap.xml` and replace `YOUR-DOMAIN.TLD` with the real domain.
5. Add `Sitemap: https://YOUR-DOMAIN.TLD/sitemap.xml` to `robots.txt`.
6. Add the final website URL and LinkedIn URL to `sameAs` in the JSON-LD if applicable.
7. Add an absolute profile-image URL in structured data after the domain is live.
8. Decide on the exact hosting provider before writing a privacy notice / legal notice so the information is accurate.
